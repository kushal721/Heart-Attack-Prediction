    About this model

    The data

    The 303 patients of the Cleveland Clinic heart disease study (1988), as published on Kaggle. The source file has 1,125 rows, but most rows are repeated copies of the same patients. Copies are removed before anything else, so a patient can never appear in both the training and the test set.

    Corrected labels

    This copy of the data uses different codes from the UCI documentation. Its value counts match the original study exactly, which reveals what each code really means:

    • The target column is inverted. target = 1 is the group without heart disease: younger patients with a higher maximum heart rate, less ST depression, less angina and fewer blocked vessels. The model predicts disease = 1 - target.
    • Chest pain code 0 is asymptomatic, the most common type among patients with heart disease.
    • ST slope 0, 1 and 2 are downsloping, flat and upsloping. Thallium 1, 2 and 3 are fixed defect, normal and reversible defect.
    • ca = 4 and thal = 0 mark values missing from the original study. The model fills these in with the typical value.

    The method

    Patients are split 80/20 into training and test sets, stratified by outcome. Logistic regression, random forest, gradient boosting and a decision tree are each tuned with 5-fold cross-validation on the training set. The model with the best cross-validated ROC-AUC is deployed as trained and scored once on the test set.

    Limits

    About 300 patients from one hospital, collected decades ago. With 61 test patients, the accuracy figure could move by several points on a different split. Use this to learn how such models behave. It is not a medical device and must never guide a diagnosis.
